## Repository Setup

### GitHub Pages Configuration

Navigate to:

**Settings → Pages**

Configure:

```text
Source: Deploy from a branch
Branch: main
Folder: / (root)
```

---

## Local Development

Clone the repository:

```bash
git clone https://github.com/brad-hobbswd/brad-hobbswd.git
```

Open the project folder and launch:

```text
index.html
```

in your browser.
