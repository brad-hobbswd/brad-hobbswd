Use & Permission

When You Need to Reuse Something.

If you would like to reproduce, reuse, license, or otherwise use original content from this website, contact Brad Hobbs Web Design before using the material.

Permission Requests

Requests should identify the material you would like to use and explain how and where it will be used. Written permission should be obtained before reuse.

  • Identify the specific content or design element
  • Explain the intended use
  • Provide the website, publication, or project where it will appear
  • Wait for written permission before using protected material
